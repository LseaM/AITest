# 管理后台邮箱密码登录 Spec

## 范围

本 Spec 仅覆盖已注册用户通过邮箱和密码登录管理后台，不覆盖注册、找回密码和第三方登录。

## 角色

- 已注册且状态正常的后台用户。

## 主流程

1. 用户进入登录页并输入邮箱和密码。
2. 系统校验必填项、账号状态、锁定状态和密码。
3. 校验通过后进入管理后台首页并记录审计日志。

## 原子需求

- `REQ_LOGIN_001`：状态正常、未锁定的已注册用户输入正确邮箱和密码后，应登录成功并跳转至管理后台首页。来源：`sources/login-requirement.md#功能范围`、`#权限`。
- `REQ_LOGIN_002`：邮箱和密码均为必填项，任一项为空时不得提交有效登录。来源：`sources/login-requirement.md#业务规则`。
- `REQ_LOGIN_003`：密码连续错误 5 次后账号锁定 30 分钟，锁定期间使用正确密码也不得登录。来源：`sources/login-requirement.md#业务规则`。
- `REQ_LOGIN_004`：登录成功后必须记录包含用户、时间和结果的登录审计日志。来源：`sources/login-requirement.md#业务规则`。

## 业务规则

- 密码错误计数以连续错误次数计算。
- 第 5 次密码错误触发 30 分钟锁定。

## 状态流转

- 未锁定 → 连续密码错误 5 次 → 锁定 30 分钟。
- 锁定期结束 → 未锁定。

## 权限

- 仅状态正常且未锁定的用户允许登录。

## 输入校验

- 邮箱必填。
- 密码必填。

## 接口约束

无。

## 异常流程

- 必填项缺失时拒绝有效登录。
- 密码错误时拒绝登录并累计连续错误次数。
- 账号锁定期间拒绝登录。

## 非功能要求

无。

## 验收标准

- 正常用户可进入管理后台首页。
- 必填校验、连续错误锁定和锁定期拒绝登录均符合原文规则。
- 成功登录产生完整审计日志。
